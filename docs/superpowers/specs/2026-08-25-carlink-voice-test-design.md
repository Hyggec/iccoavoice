# Carlink 低噪环境语音端到端测试台设计

## 目标

提供一个双击即可打开的本地 HTML 测试台，用四种中文自然语音播放完整业务语料，并记录车机端到端执行成功/失败，实时计算完成率及 93% 门槛状态。

## 交互

- 顶部显示测试标题、低噪环境要求（45±2 dB）和目标完成率（≥93%）。
- 业务分为导航、拨打电话、音乐播放、其他。
- 每条语料显示性别/音色、文本、播放按钮和成功/失败按钮。
- 播放单句前会停止当前音频；支持整组顺序播放、暂停、下一条。
- 124 个测试项默认全部通过；发现失败时改为未通过，也可恢复通过。
- 成功/未通过操作更新计数；支持撤销最后一条、重置为全部通过。
- 完成率按成功次数/已记录次数计算，未记录时显示“—”。
- 连续播放每句结束后默认等待 20 秒，显示倒计时和进度，并支持立即下一句、暂停等待及 1–120 秒调整。
- 移动端使用单列语料卡、大触控按钮和固定底部等待控制，无横向溢出。

## 音频

使用 Microsoft Edge 在线自然语音音色生成 MP3。每条语料生成四个版本：Yunxi 男声、Yunyang 男声、Xiaoxiao 女声、Xiaoyi 女声。资源文件使用 ASCII 文件名，避免本地路径编码问题。

## 技术边界

- 原生 HTML/CSS/JavaScript，无构建工具、无外部运行时依赖。
- `audio/` 保存 MP3，`index.html` 使用相对路径加载。
- `generate_audio.py` 负责批量生成和重试。
- `tests/test_app.mjs` 验证语料数量、四音色覆盖和完成率计算函数。

## 验收

- 共 31 条基础指令、124 个音频文件。
- 单句点击可播放；播放另一句会停止上一句。
- 成功/失败计数准确，完成率格式正确，达到 93% 时显示通过。
- 页面在 Chromium/Edge 本地打开，无需服务器。
